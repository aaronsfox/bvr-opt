# Welte 2022 rater-error data (digitised)

Values digitised from Welte et al. (2022) to calibrate simulated rater keyframes.
- `welte2022_fig4_rater_bias_summary.csv`: Fig 4 medians per rater group, bone and DOF.
- `welte2022_fig5_new_operator2_rotation_bias.csv`: Fig 5 rotation bias for a new operator.

Fitted offset + random model (rotation): calcaneus 0.66° offset + σ 0.22°, talus 0° + σ 0.29°,
tibia 0.63° + σ 0.27°; tibia occlusion failure over 6 frames, 2.6–3.8°.
